# Cybersecurity Dashboard

A front-end dashboard for viewing security-related indicators in one place. The interface groups threat events, traffic information, port status, and activity logs.

## Dashboard sections
- Overall security status.
- Threat monitor with severity labels.
- Network traffic monitor.
- Port status.
- Activity logs.

## Run locally

~~~bash
git clone https://github.com/ahmadfas213-cell/cybersecurity-dashboard.git
cd cybersecurity-dashboard
~~~

Open index.html in a browser or serve the folder with a local static server.

## Stack
HTML, CSS, and JavaScript.

## Project scope
This repository is a dashboard interface/demo. The displayed indicators should not be treated as live security telemetry unless connected to a real data source.
